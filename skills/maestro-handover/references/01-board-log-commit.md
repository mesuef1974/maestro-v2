## تحديثُ اللوحة
1. شغّل `render_auto_sections.py --no-fetch` واستبدل §2 و§3 بمخرجه كما هو (العنوانُ يحمل «[آلي — الدوحة <الوقت>]»؛ لا تحرّر الأرقام يدويّاً).
2. «أشجارٌ بلا اسم» في §3 تعني نقصاً في `session_names.json` — أضِف ما تعرف صاحبَه، واسأل عمّا لا تعرف (لا تخمّن اسمَ جلسة).
3. §1 (≤ ستّة أسطر في جدوله): الإنتاج، 8500، الطابور وCI، السعة (رقمُ الذاكرة ووقتُه من `watch_once`)، التقويم، وما يلزم من سطورٍ حيّة. كلُّ خانةٍ «لماذا» بمصدرٍ ووقت.
4. §4 من `ledger.py list` مرتَّباً بالأولويّة ثمّ زمن البدء؛ لا بندَ بلا زمنٍ وأولويّة (D-28م).
5. §5 مطابقٌ لـ`handover.md` §1، ≤8 بنود، كلٌّ بصيغة BLUF: القرارُ المطلوب ← الأثر ← أين يُعاين.
6. §6 أو «لا شيء». ثمّ `wc -l board_state.md` ≤150؛ فإن زاد فانقل التاريخَ إلى السجلّ واختصر، ولا ترفع الحدّ.

## تدويرُ السجلّ
- حدثٌ مضى = سطرٌ واحدٌ في سجلّ اليوم؛ اللوحةُ تبقى على الحاضر.
- يومٌ جديد (بتوقيت الدوحة) = ملفٌّ جديد `log_YYYY-MM-DD.md` في جذر مجلّد المايسترو، أوّلُ سطرٍ فيه عنوانُ اليوم. الملفُّ القديم لا يُعاد تسميتُه ولا يُحذف.
- اسمُ الملفّ الجاري يُذكر في روابط اللوحة (§7 في القالب) و`handover.md` §6.

`\b[0-9]{8,}\b|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}|\+?974[ -]?[0-9]{4}`
- نتائجُ متوقَّعةٌ غيرُ حسّاسة (تشغيلٌ 09-28): تواريخُ معرّفات البطاقات (`W-20260928-…`) وإيداعاتٌ مختصرةٌ أرقامُها عشريّة (`48201849`).
- كلُّ ما سواها يُراجَع: رقمٌ وظيفيٌّ أو وطنيّ، هاتف، بريد، اسمُ شخص، نصُّ رسالة مستخدمٍ حرفيّاً ← يُحذف أو يُستبدل بوصفٍ عامّ قبل الإيداع. المستودعُ خاصّ، لكنّ PDPPL لا يستثني الخاصّ.

## الإيداعُ والدفع (مستودعُ المايسترو الخاصّ وحدَه)
```
git -C C:/Users/mesue/delivery_manager_work pull --ff-only
git -C C:/Users/mesue/delivery_manager_work status --short
git -C C:/Users/mesue/delivery_manager_work add decisions.md flow_changelog.md board_state.md handover.md raid.md log_<اليوم>.md
git -C C:/Users/mesue/delivery_manager_work commit -m "<المايسترو: خلاصةٌ عربيّةٌ بالقرار ورقمه>"
git -C C:/Users/mesue/delivery_manager_work push origin main
```
- المساراتُ صراحةً: `git status` يوم 09-28 أظهر ملفّين غيرَ متتبَّعين في `docs/` تركتهما جلسةٌ أخرى؛ `add -A` كان سيودعهما باسمك.
- `pull --ff-only` يفشل إن تباعد الفرعان: لا `--rebase` على شجرةٍ متّسخة ولا `stash`؛ أودِع عملَك أوّلاً ثمّ ادمج (قواعدُ غيت العامّة في `schoolos-git-safety`).
- الرسالةُ بالعربيّة وتبدأ بالمعرّف أو «المايسترو:» (نمطُ السجلّ)، وتنتهي بسطر الإسناد الذي تطلبه جلستُك.
- `ledger/events.jsonl` متجاهَلٌ في `.gitignore` عمداً (سجلٌّ آليٌّ كثيرُ التغيّر، D-56م)؛ لا تُجبره.
- لا دفعَ ولا دمجَ في مستودع المنصّة `D:/shschool_mvp` من هذه المهارة ولا من غيرها (D-36م، D-37م، ميثاقُ 0101).
