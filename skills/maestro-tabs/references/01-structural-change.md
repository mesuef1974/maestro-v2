## 3) فحصُ انحراف المواثيق بلا كتابة
`render_charters.py` يكتب دائماً؛ فللتحقّق وحدَه (هل `docs/tab_charters.md` يطابق tabs.json؟):
```bash
cd C:/Users/mesue/delivery_manager_work/tools && python -X utf8 -c "
import json, importlib.util; from pathlib import Path
s = importlib.util.spec_from_file_location('rc', 'render_charters.py'); m = importlib.util.module_from_spec(s); s.loader.exec_module(m)
t = json.loads(Path('../projects/schoolos/tabs.json').read_text(encoding='utf-8'))
print('متطابق' if m.render(t) == Path('../docs/tab_charters.md').read_text(encoding='utf-8') else 'انحراف: شغّل render_charters.py')"
```
جُرّب 09-28 21:00: «متطابق». هذا الأمرُ خارج `allowed-tools` عمداً (يطلب إذناً).
