## المرحلة 3 — الربط بالأتمتة

### 3.1 التوجيه المبكر للمحظور
- **مصدر واحد:** خانات «يمسّ» تُبنى من جدول صغير: الأمن ← `*/security/*`، `security/*` · الصلاحيات ← `*permissions*` · الهجرات ← `*/migrations/*` · الأدوار ← `*rbac*`، `*roles*`، `*Role*`. ومعه اختبار يفشل إن لم يساوِ اتحادُ الأنماط `FORBIDDEN_GLOBS` في `scripts/auto_merge_gate.py` (السطران 40-48).
- خانة مختارة، أو ملف معلن يطابق المحظور ← الاستمارة تقول قبل الإرسال: «لن يُدمج آليًّا: يلزم قرارك في طابور المالك، والأمن يحتاج «أقرّ أمنيًّا»». والبطاقة تُسجَّل بـ`runner_hold` فيتخطّاها `pick_card`، وتدخل طابور المالك.
- بعد كتابة النموذج: إن لمس الفرق المحظور ولم يُعلن ← إيقاف قبل فتح طلب الدمج، وتقرير «خرج النموذج إلى منطقة محظورة». والإعلان استشاريّ: غير المُعلَن تردّه البوّابة كما اليوم.

### 3.2 الاعتماد لكل طلب (قرار المالك D-528م)
- حقل «الاعتماد»: «نشر مباشر بعد البوّابة» أو «أعاين على 8500 قبل الدمج». الافتراضي معاينة لـ«تحسين واجهة» و«تصميم»، ومباشر لغيرهما.
- **مباشر:** المشغّل يكتب صيغة D-58م التي يقبلها تعبير `APPROVAL` في البوّابة: «اعتُمد من المالك مباشرةً بلا معاينة 8500 — YYYY-MM-DD — الرأس <sha8>».
- **معاينة:** بعد نجاح الحاوية يضع المشغّل البطاقة في طابور المالك بحالة «جاهز للمعاينة» ويتوقّف. بعد اعتماد المالك يُكتب «اعتُمد من المالك على 8500 — YYYY-MM-DD — الرأس <sha8>» ويستأنف.

### 3.3 رقم فوري و«طلباتي» والإلغاء
- الإرسال يعيد رقمًا فورًا (`R-YYYYMMDD-NNN`)، ويظهر رقم البطاقة `W-…` بجانبه حين يلتقطه المشغّل (خلال 5 دقائق).
- قسم «طلباتي» في الصفحة نفسها، يُقرأ من `requests/` والدفتر دون كتابة: الرقم، والعنوان، والوقت، والحالة (في الانتظار ← التُقط ← النموذج يكتب ← الحاوية ← طلب الدمج #N ← البوّابة ← انتظار الدمج ← انتظار النشر ← منشورة / أُغلقت بتقرير / أُلغيت)، والكلفة والمحاولات، ورابط إلى «المشغّل الحيّ».
- **الإلغاء قبل الالتقاط فقط:** `POST /request/<id>/cancel` (بشروط 0.1 نفسها) ينقل الطلب إلى `requests/cancelled/` بـ`os.replace`. والمشغّل يلتقط بنقل ذرّي إلى `requests/picked/`، فمن ينقل أولًا يفوز.

### 3.4 سقف الكلفة والمحاولات
- قبل الإرسال سطر: «النموذج: haiku · متوسّط البطاقات المشابهة <x$> · السقف <y$> و<n> محاولات»، محسوبًا من سجل ميزان بلا توكنز.
- حقل السقف بقيمة افتراضية حسب الحجم (تُعايَر من السجل)، وعدد المحاولات الافتراضي 3.
- المشغّل يقارن قبل كل تشغيل للنموذج؛ التجاوز ← إغلاق بتقرير «بلغ السقف» وإحالة إلى طابور المالك. (بطاقة 010 بلغت 7 محاولات و12 تشغيلًا لتصحيح تعليق واحد.)

### 3.5 إغلاق الحلقة
- حقل اختياري «بند الخارطة» (VI- أو LAY- أو N-…) مع تحقّق من الصيغة. بعد النشر يكتب المشغّل في الدفتر: «W-… نُشرت (#PR) وتخصّ البند X»، فيُغلَق البند تلقائيًّا.
- زر «أعد المحاولة» في «طلباتي» لكل طلب أُغلق بتقرير: يملأ الاستمارة بالطلب الأصلي، ويضيف سبب الإغلاق، ويحفظ `retry_of: R-…`.

### 3.6 «رسم الأتمتة»
- إضافة مسار المشغّل (D-519م): الاستمارة ← requests/ ← المشغّل ← النموذج ← الحاوية ← طلب الدمج والبوّابة ← النشر ← منشورة، مع فرعَي التوجيه المبكر والمعاينة (طابور المالك ← 8500 ← اعتماده).
