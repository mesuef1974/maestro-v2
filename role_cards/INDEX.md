## إلى مَن أذهب؟
- مهمّةٌ جديدة أو اكتشافٌ أثناء العمل ← **0101** (بطاقة بزمنٍ وأولويّة ثمّ تصنيفٌ وتسمية؛ وميثاقا البوابة والمستشار القديمان [0201 و0301] مدمَجان فيها).
- توجيهٌ وأولويّاتٌ وأزمات ← **0101**. ورصدُ المنظومة وتقييمُها ← **0201**. وخللٌ في المنظومة أو الفلو أو السجلّ ← **0301** (الحوكمة، كانت 0103؛ وميثاقُ 0102 مدمَجٌ فيها).
- جاهزٌ للمعاينة واعتمادُ المالك ← **0501**. دمجٌ ونشرٌ وطلباتُ الدمج ← **0601**.
- حكمٌ على تنبيهٍ أمنيٍّ أو ثغرة ← **0104** (0701 ترصد وتحيل). امتثالٌ وقانونٌ وقواعدٌ ← **0301**.
- خيارات مقيسةٌ لقرارٍ مفتوحٌ ← **0301**. مرجعٌ وزاريٌّ وتصنيفٌ وتسمية ← **0101**.
- خارطةٌ بعد الدمج وقياسُ جودةٍ بعد النشر ورصدٌ وأتمتةُ مهمّةٍ دوريّةٍ في الكود ← **0701** (ميثاقُ 0702 مدمَجٌ فيها).
- رقمٌ قديمٌ أو مدمَجٌ يُخاطَب بمستقبِلته (`session_policy.aliases`؛ قديمٌ ← حاليّ): 0102 ← 0301، 0103 ← 0301، 0105 ← 0104، 0202 ← 0101، 0203 ← 0701، 0204 ← 0101، 0702 ← 0701، 0801 ← 0701.
