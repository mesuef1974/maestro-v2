# سجلُّ التنبيهات المستبعَدة

> القاعدة (D-101م): الحكمُ «إيجابيٌّ كاذب» يُسجَّل هنا **بدليل قراءة الكود قبل أيّ طلب استبعاد**. على تنبيهٍ بدرجة high: **قارئٌ ثانٍ مستقلٌّ** قبل الاستبعاد (قراءةٌ من جلسةٍ أخرى أو إعادةُ تشغيل CodeQL بعد تعديلٍ شاهد). والاستبعادُ الفعليّ في GitHub عمليّةٌ لـ0601 بإذن المالك — 0105 تُعدّ الدليلَ والطلب.

| التاريخ | التنبيه (المصدر · القاعدة · الملفّ:السطر) | الدرجة | الحكم | دليلُ التحقّق (ما قُرئ بالضبط) | القارئُ الثاني (high) | من أقرّ | نُقض لاحقاً؟ |
|---|---|---|---|---|---|---|---|

ملاحظةُ البدء (مُحسومة بإفادة 0101): تنبيهاتُ py/path-injection الأربعة في docs_viewer (116/117/119/120) **مفتوحةٌ في GitHub بلا dismissed_reason ولا fixed_at** (قياسُ 0105 المباشر 2026-10-02، وهي الأسطرُ القديمةُ نفسُها). ما أُغلق ليلةَ 2026-10-01 هو **بطاقةُ السجلّ** W-20261002-001 (كإيجابيٍّ كاذب بقراءة الكود)، لا التنبيهاتُ؛ ولم يُنفَّذ استبعادٌ فعليٌّ قطّ. اختار المالكُ **الإصلاحَ بالكود**: قيدُ الإصلاح #772 (بطاقةُ W-20261002-004، تنفيذُ 0410)؛ **الاستبعادُ احتياطٌ فقط** إن لم يُغلق CodeQL التنبيهاتِ بعد الدمج، بإذن المالك المباشر. وتتحقّق 0105 بـgh api بعد الدمج.
