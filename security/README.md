# مجلّد الأمن — مخرجاتُ «0104 · الأمان: الثغراتُ والتنبيهات» (D-101م)

جلسةُ 0104 في وضع plan فلا تكتب ملفّات؛ تُرسل مخرجاتِها رسائلَ، ويكتبها 0102 أو 0101 هنا. المجلّدُ خارجَ مستودع المنصّة عمداً: فيه تفاصيلُ ثغراتٍ لا تُترك مع الكود.

| الملفّ | الغرض |
|---|---|
| `excluded_alerts.md` | سجلُّ المستبعَدات: تنبيهٌ حُكم عليه إيجاباً كاذباً أو مقبولَ الخطر، بدليله ومن أقرّه |
| `sensitive_paths.json` | مسارات الفئة الإلزاميّة للمراجعة الأمنيّة قبل المعاينة (قائمةٌ ثابتة تقرؤها البوّابة) |
| `incident_runbook.md` | دليلُ الحوادث القصير (0104 مع 0103) |
| `reports/` | تقاريرُ الفحص بعد النشر والأسبوعيّة (اسمُ الملفّ بتاريخه ورقم الإيداع المنشور) |

القواعد: لا أسرارَ ولا بياناتٍ شخصيّةً في أيّ ملفّ هنا؛ كلُّ سطرٍ بتاريخه؛ لا إغلاقَ بلا دليلِ تحقّقٍ مباشر.
